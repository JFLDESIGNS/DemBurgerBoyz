# Burger Pals cards

Original deck box, back and rank-neutral portrait atlas generated with the built-in image generation tool. The 3 x 2 atlas contains box front, back, king, queen, jack, and ace medallion. Runtime code adds all ranks and suits; portraits contain neither.

Prompt: Original Burger Pals diner playing-card atlas, cream/red/teal vintage ornamental box and back, friendly burger king/queen/jack and ace burger medallion. Flat artwork, blank label corners, no rank letters or suit marks on portraits. Revisions removed baked-in corner labels, suit symbols, and queen heart ornaments.

Suit marks are original procedural vector shapes drawn by scripts/playing_card.gd; no external icon license or font dependency. Games use no wagers. The host holds the shuffled deck and sends only each participant's hand; blackjack dealer hole card remains hidden until the round ends.
